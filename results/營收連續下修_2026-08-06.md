> 原始問題:「法人 EPS 預估連續下修中的個股,買進後 60 天報酬如何」+「便宜是不是買進理由」。

## 為什麼不是照字面驗

台股拿不到分析師共識 EPS 預估:FinMind 免費只有已公布實際數;TEJ/CMoney/IBES/Bloomberg 全付費;
公開資訊觀測站財務預測 2005 後改自願、樣本近零;券商研報不可系統性取得且有倖存者偏誤。
已 grep 全 repo(`framework/` `studies/` `backfill/`)`eps|forecast|預估|consensus|財測` **零命中**。

**代理變數**:月營收 YoY 的連續遞減。因果上是分析師砍預估的**上游**(營收每月 10 日前先公布,
EPS 預估之後才改),時效性更好且完全 point-in-time。

## 訊號定義

`streak` = 最近連續幾個月 YoY 低於前一個月(月份須相鄰,跳月歸零)。

| 代號 | 定義 |
|---|---|
| A | `streak >= 3` — 下修中(不管水準) |
| B | `streak >= 3` 且 `yoy < 0` — 下修中 + 已衰退 |
| A′ | `streak_up >= 3` — 連續上修(反面對照) |
| C / C′ | YoY 最低 / 最高分位 — **對照組**,已知答案,用來驗腳本 |

### ⚠️ 別誤讀輸出裡的「未通過」

`calibrate.py` 每組末行印 `效果量❌ 非集中❌ 非少數時點❌ → 未通過`。
**那個 gate 是設計來找「可做多的 edge」**,要求效果量為正、日期為正比例高。
A 組效果量本來就是負的,「未通過」是必然,**不構成對 H1 的否定**。
§0 登記的判定條件是百分位,不是該行 ✅/❌。同理 `🔴 判決:少數標的/少數時點撐起來的`
描述的是獲利集中度,套在空方訊號上語意不成立。

## Phase 2 — 「便宜是不是買進理由」(2026-08-06 同日執行)

腳本 `studies/revenue_downgrade_valuation.py`,估值資料 `backfill/backfill_valuation.py`
(TWSE `BWIBBU_d`,178 個再平衡日 2011-01-04~2026-03-25,**成功 178、失敗 0**)。

- 切估值用 **PB 不用 PE**:實測 PE 覆蓋僅 ~810/1068 檔,而下修組正好大量虧損(PE 印 `-`),
  用 PE 會系統性剔除最慘的那批 → 直接偏誤。PB 覆蓋 1068/1068。
- 切法 = **每個再平衡日在 A 組內取橫斷面中位數**,不是全期固定門檻(PB 絕對水準 16 年會漂移,
  固定門檻等於在比年代不是比貴賤)。
- A 組 PB 覆蓋率 96%(9692/10047 列),缺的是上櫃。**結論樣本僅含上市。**

### 樣本內(160 個再平衡日)—— 兩個半邊沒有實質差別

| | 持有 20 日 | 持有 60 日 |
|---|---|---|
| A 全體(有PB) | -1.05% | -0.68% |
| ├ 便宜半邊(低PB) | -1.15% | -0.70% |
| └ 貴半邊(高PB) | -0.95% | -0.65% |
| **便宜 − 貴** | **-0.19%** | **-0.04%** |

兩半邊校準百分位都是 **0.0**(都遠比隨機爛)。便宜半邊分年 14 年有 13 年為負,
bootstrap -2.10% CI[-2.50,-1.70] p=0.0。

**判定為「持平」不是「陷阱」,三個理由:**
1. H=60 差 0.04%/20日 —— **低於偵測門檻**(0.10~0.25%/20日)。
2. **換統計量排序就翻**:平均是貴的好(-0.65 vs -0.70),個股中位數是便宜的好(-2.27 vs -3.31)。
   翻轉來自集中度 —— 貴半邊前5檔佔比**百分位 99**(便宜 88),平均被少數暴衝股拉起,典型股更慘。
3. **PB 五分位完全不單調**:H=60 為 -0.56/-0.74/-0.69/-0.74/-0.66,五格擠在 0.2 個百分點內、
   無排序;最便宜那格甚至最不慘。

> ⚠️ **腳本自動標籤不可信**:`revenue_downgrade_valuation.py` 印的「便宜更慘(價值陷阱)」
> 只判 `if d < 0`,-0.04% 也會觸發。**看數字不要看標籤**。這類自動標籤會誤導未來的自己。

| | 持有 20 日 | 持有 60 日 | 校準百分位(H=60) |
|---|---|---|---|
| 便宜半邊(低PB) | -2.32% | **-2.06%** | **0.0** |
| 貴半邊(高PB) | -0.80% | **-0.22%** | **47.5**(≈隨機) |
| **便宜 − 貴** | **-1.52%** | **-1.84%** | |

PB 五分位 H=60 **變成單調**:-2.62 / -1.65 / -1.48 / -0.46 / **+0.49**。

**兩段期間結論相反**:樣本內(160 日)說沒差別,樣本外(14 日)說差很大。
以樣本量論**樣本內應該主導**。樣本外這個型態最合理的解釋是
**2025-26 的成長>價值 regime**(低 PB 價值股被輾、高 PB 成長股撐住),
與判決表「52週高 OOS 廣度崩掉、獲利由右尾少數股撐起,符合權值/AI 窄幅行情」是同一件事。

⚠️ **未做的診斷**:同期(2025-26)**全市場**的 PB 五分位是否也單調?
若是 → 上表是 regime 效應,與「下修中」無關。這個檢查沒做,所以**不能宣稱
「下修 + 便宜」有特殊的交互作用**。

### Phase 2 判定(SPEC §0 事前登記)

> 便宜半邊 **更差或持平** → 便宜不提供保護,「便宜」不是買進理由
> 便宜半邊 **明顯較好** → 估值有緩衝作用,值得續查

**樣本內「持平」、樣本外「更差」,兩段都不是「明顯較好」→ 判定成立:「便宜」不是買進理由。**

精確講法:**估值在「營收持續下修」這批股票裡沒有穩健的區別力**。
不是便宜會害你(那需要樣本內也顯示便宜更差),是**便宜救不了你** —— 下修本身壓過估值。
「便宜更慘」只在 2025-26 這個 regime 成立,不可外推。

## 結論

1. **H1 成立**:營收動能連續惡化中的股票,買進後 peer 超額顯著為負(百分位 0.0)。
   「還在變爛」是負面訊號,**不是逆向抄底的理由**。
2. **A′ 反面對照成立**:連續上修 H=60 為 +0.27%(百分位 100),與 A 分居兩邊
   → 是**動能方向**,不只是「爛股會跌」。
3. **與判決表既有結論一致**:抄底類(52週低 -1.16%、YoY最低分位 -1.19%、KD超賣/RSI最低
   -0.92~-0.96%)在台股是系統性虧損。本輪把「持續性」也放進同一邊。
4. **「便宜」不是買進理由**(Phase 2)。下修組內按 PB 切兩半,便宜半邊沒有明顯較好:
   樣本內持平(差 0.04%/20日,低於偵測門檻)、樣本外更差(-1.84%,但屬 2025-26 regime)。
   **估值救不了「還在變爛」。**
